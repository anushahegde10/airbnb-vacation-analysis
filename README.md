# Airbnb Popular Vacation Destinations

A global Airbnb market analysis examining occupancy trends, pricing patterns 
and seasonal demand across 10 major cities using Power BI.

## Project Overview

This project was submitted to the **Maven Analytics Vacation Challenge**. This is a 
data challenge using real Airbnb data from 2008 to 2021.

The goal was to uncover what drives occupancy and pricing across global vacation 
destinations, and how the pandemic changed travel behaviour permanently.

## Key Insights

- **Paris** is the most preferred destination with ~100k reviewed stays per year
- Global prices have remained consistent at ~$45/night since 2010
- Price is driven by city, property type and host rating and not by season
- **Sydney, Cape Town and Paris** have the highest average nightly prices
- **Rome and Mexico City** offer the best value for travellers
- Pandemic caused ~50% decline in occupancy globally
- Most preferred accommodation type is **Entire Apartment**
